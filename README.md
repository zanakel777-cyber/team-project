# Mūsų komandos projektas

Mokomasis projektas, kuriame du žmonės mokosi dirbti su viena bendra GitHub repozitorija: Commit, Push, Pull, Fetch ir Merge konfliktų sprendimas.

## Ką daro

- Paspaudimų skaitiklis
- Atsitiktinė žinutė
- Balsavimo mygtukai „Taip" / „Ne" su rezultatu
- Komandos narių kortelės

## Kaip paleisti

Serverio nereikia – tai paprastas statinis puslapis.

1. Parsisiųsk projektą:
   `git clone https://github.com/zanakel777-cyber/team-project.git`
2. Atidaryk aplanką
3. Dukart paspausk `index.html` – atsidarys naršyklėje

## Failai

- `index.html` – puslapio turinys ir visi elementai
- `style.css` – spalvos, kortelių ir mygtukų išvaizda
- `script.js` – visų mygtukų logika
